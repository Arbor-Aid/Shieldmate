# SEO Veteran Nonprofit Ranking Plan

Date: 2026-06-02
Status: docs-only SEO plan

## SEO Objectives

- Rank the 2Marines public hub for branded and mission searches.
- Build relevance for veteran support, partner coordination, and nonprofit support workflows.
- Make ShieldMate discoverable for support workflow and partner organization software terms.
- Keep MarineCoin indexed as a store/support lane, not as crypto or investment content.

## Page-Level SEO Tasks

### Public hub

- Add a clear H1 that names 2Marines and veteran support/partner mission.
- Add 300-600 words of mission copy with links to ShieldMate, Store, and MarineCoin.
- Include internal links to `/shieldmate`, `/store`, and `/marinecoin`.
- Add organization summary, contact pathway, and social links.
- Avoid unsupported legal status claims.

### ShieldMate page

- Add product copy around intake, referrals, partner coordination, documents, and follow-up.
- Add a "who it is for" section for veteran support teams and partner organizations.
- Add FAQ content targeting case management and nonprofit workflow search intent.
- Link to the public hub and store route.
- Avoid software capability claims that are not live or approved.

### Store route

- Keep `/store` as the public SEO route even when it redirects to Shopify.
- Document canonical behavior before SEO implementation.
- If a local store landing page is added later, include store intro copy and a clear Shopify handoff.
- Avoid duplicating Shopify product descriptions unless canonical tags and page roles are planned.

### MarineCoin page

- State clearly that MarineCoin is store/support/product related.
- Avoid cryptocurrency, token, investment, profit, or financial-return language.
- Link to `/store` for purchase intent.
- Add FAQ content that clarifies product/support purpose.

## Technical SEO Checklist

- Verify each target page has one H1.
- Verify title tags and meta descriptions are unique.
- Verify Open Graph and Twitter metadata use canonical URLs.
- Confirm `/store` redirect behavior is intentional and documented.
- Add sitemap entries only after deployment path is confirmed.
- Add structured data later only after legal/entity details are approved.
- Keep URLs lowercase and stable.
- Do not index preview channels.

## Internal Linking Plan

- Public hub links to ShieldMate, MarineCoin, and Store.
- ShieldMate links back to Public Hub and Store.
- MarineCoin links back to Public Hub and Store.
- Store route links or redirects to Shopify.
- Footer should expose Public Hub, ShieldMate, MarineCoin, Store, and Socials.

## Measurement Plan

- Google Search Console: track indexed pages, queries, click-through rate, and coverage issues.
- Google Ads: track search terms, landing page quality signals, and conversion paths.
- Analytics: track page views, outbound Shopify clicks, and ShieldMate CTA clicks.
- Review ranking movement weekly after any public content changes.
