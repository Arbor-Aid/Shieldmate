# MCP Environment Variables

## Common
- PORT (default 8080)
- SERVICE_NAME
- SERVICE_VERSION
- SLACK_WEBHOOK_URL (optional; do not print)
- DATASET_BASE_URL (for website JSON exports, e.g., https://2marines.us/data)
- FIREBASE_PROJECT_ID (optional)
- LOG_LEVEL

## Per-service
### mcp-gateway
- GIT_SHA
- K_REVISION
- LOG_LEVEL
- PORT
- SERVICE_NAME
- SERVICE_VERSION
