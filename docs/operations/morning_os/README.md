# ShieldMate Morning Operating System

Purpose: organize Joshua's morning startup routine before ShieldMate launch work begins each day.

This package is documentation and planning only. It does not authorize deployment, posting, scheduling, launch activity, ad spend, account mutation, or live API checks.

## Files

- `MORNING_STARTUP_CHECKLIST.md`: daily startup steps, repo checks, venv activation, branch/status checks, and thebot admin script verification.
- `REQUIRED_WINDOWS_AND_TOOLS.md`: recommended windows, browser tabs, and tool groups.
- `MCP_HEALTH_AND_PROTECTED_ROUTE_CHECKS.md`: safe placeholder command shapes for MCP health and protected-route checks.
- `LOCAL_FILE_ORGANIZING_WORKFLOW.md`: local-first file organization, naming conventions, and cleanup routine.
- `AI_MEMORY_AND_DEEP_AGENT_RESEARCH_PLAN.md`: research plan for persistent memory, task logs, daily summaries, and grounded agent context.
- `LANGUAGE_ROLES.md`: language boundaries for PowerShell, Python, TypeScript, and C#.
- `MORNING_AI_NEWSLETTER_WATCHLIST.md`: topics to review for AI, cloud, marketing, compliance, and public-safety technology.
- `PHONE_TABS_TO_GOOGLE_DOC_WORKFLOW.md`: manual workflow for moving useful phone tabs into Google Docs and later repo docs.
- `AXON_PUBLIC_SAFETY_AI_CASE_STUDY_NOTES.md`: research stub for public-safety AI lessons.

## Morning Flow

1. Open the required local tools.
2. Activate `.venv`.
3. Confirm branch and git status.
4. Confirm task scope.
5. Confirm browser tabs and account context.
6. Sort local files and notes.
7. Run only approved read-only checks.
8. Start the day's work.

## Guardrails

- Do not commit secrets, tokens, private emails, billing data, or credentials.
- Do not paste live tokens into docs or chats.
- Do not publish, schedule, deploy, launch, spend, or mutate accounts from this routine.
- Mark unknown paths and URLs with placeholders until Joshua confirms them.
