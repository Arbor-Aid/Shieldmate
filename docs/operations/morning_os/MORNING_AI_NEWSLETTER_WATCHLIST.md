# Morning AI Newsletter Watchlist

Purpose: provide a topic checklist for Joshua's morning review.

This is not live news. These are topics to review when Joshua chooses to check newsletters, vendor blogs, release notes, or trusted sources.

- Firebase Hosting changes.
- Firebase Auth or App Check notes.
- Cloud Run updates.
- Firestore rules or billing notes.

GitHub Actions and repo health:

- Failed checks.
- Security alerts.
- Dependency updates.
- Branch or PR activity.

Flutter and web build notes:

- Flutter release changes.
- Web build tooling changes.
- Browser compatibility notes.
- Package deprecations.

Meta Business and ad policy:

- Meta Business Suite workflow changes.
- Organic scheduling changes.
- Ad policy updates.
- Account access and billing policy notes.

Canva workflow:

- Bulk Create workflow changes.
- Export format updates.
- Team asset or brand kit changes.
- Template and field mapping tips.

Public safety AI, privacy, and evidence workflows:

- Evidence handling rules.
- AI summarization risks.
- Audit trail expectations.
- Privacy and retention updates.

Veteran services technology:

- Referral coordination tools.
- Housing and benefits navigation technology.
- Community support platforms.
- Nonprofit data privacy practices.

AI agent tooling:

- Filesystem memory patterns.
- Agent audit logging.
- Human approval gates.
- Retrieval and grounding techniques.

Cybersecurity and compliance:

- Credential hygiene.
- Token storage.
- Phishing or account compromise alerts.
- Data retention and access review practices.
