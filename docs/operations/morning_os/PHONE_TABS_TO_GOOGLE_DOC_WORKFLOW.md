# Phone Tabs To Google Doc Workflow

Purpose: turn useful phone browser tabs into organized project notes without leaking private account data.

## Manual Workflow

- [ ] Open the phone browser tabs.
- [ ] Identify the tabs worth keeping.
- [ ] Share important tabs to a Google Doc.
- [ ] Label each link by project.
- [ ] Add one line explaining why the link matters.
- [ ] Close old tabs that are no longer useful.
- [ ] Later, add useful public-safe links to the correct repo doc.
- [ ] Do not paste private or sensitive account pages into docs.

## Google Doc Format

```text
Date:
Project:
Link:
Why it matters:
Action:
Repo doc to update:
Sensitive/private data present:
```

## Project Labels

- Public safety AI research.

## What Not To Save

- Account settings pages.
- Billing pages.
- Pages showing private emails.
- Pages showing tokens, keys, or credentials.
- Screenshots with private names, phone numbers, emails, or case details.
- Anything that should stay local-only.

## Repo Follow-Up

When a link should become part of repo knowledge:

- Confirm the link is public-safe.
- Add it to the relevant doc with a short reason.
- Mark live-research conclusions as date-specific.
- Keep private notes in local-only storage.
