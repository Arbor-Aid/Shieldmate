# Ecosystem Communication Map

Audit date: 2026-06-03

This map documents how the 2Marines, ShieldMate, MarineCoin, Firebase, MCP, commerce, ads, analytics, and app-release surfaces should communicate. It is documentation only; it does not approve deploys, external mutations, new credentials, or security-rule changes.

## Hosting Target Map

| Surface | Firebase project | Hosting target | Hosting site |
| --- | --- | --- | --- |
| 2Marines main site | `marines-ai-agent` | `marines-ai-agent` | `marines-ai-agent` |
| ShieldMate site/app | `marines-ai-agent` | `shieldmate` | `2m-shieldmate-48cad` |
| MarineCoin site | `marines-ai-agent` | `marinecoin` | `marinecoin-2marines` |

Public `frontend/web/index.html` uses safe static default ecosystem metadata.
Site-specific metadata may be handled later through a safe metadata injection
strategy. Raw `%VITE_*` placeholders must never ship to production or built
output.

## Contact Email Deployment Note

Root cause for the `hello@2marines.us` vs `info@2marines.us` mismatch: source and local `frontend/web/dist` contained `info@2marines.us`, but `shieldmate.2marines.us` is served by Hosting target `shieldmate` / site `2m-shieldmate-48cad`. Deploying `hosting:marines-ai-agent` updates the main site target and does not update the ShieldMate hosting site.

Rule: always deploy the Hosting target that matches the custom domain being tested.

| Domain being tested | Required target |
| --- | --- |
| `2marines.us` / `www.2marines.us` | `hosting:marines-ai-agent` |
| `shieldmate.2marines.us` | `hosting:shieldmate` |
| `marinecoin.2marines.us` | `hosting:marinecoin` |
